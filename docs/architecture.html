Hamster of Orion — the software stack

A zero-dependency, zero-build 4X strategy game. Plain HTML + CSS + vanilla JavaScript: 27 IIFE modules share one global namespace (HOO), and the <script> order in index.html is the dependency graph.

The stack, layer by layer

Each layer only calls the layers below it, through the shared HOO namespace. index.html loads scripts bottom-up (foundation first, bootstrap last), so every global a module needs already exists when it runs. Click any module for details, or

Module size — lines of code by layer

11,010 lines of JavaScript, hand-written with no framework. The UI layer is the heaviest (screens.js alone is 1,251 lines); the game engine carries the MOO-1993 rules; the foundation is a tiny 123-line utility belt. Hover a bar for detail.
