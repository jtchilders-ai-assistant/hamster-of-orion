# High Council UI - Detailed Wireframe Specification

## Overview

The High Council screen in Hamster of Orion is the interface for the Galactic Council voting system, where races elect a **Master of Orion** through democratic vote. This specification provides detailed ASCII wireframes matching MOO1 behavior while incorporating the pet-themed lore.

**Reference**: Master of Orion (1993) High Council / Galactic Council Screen  
**Trigger**: Council convenes when 50%+ of habitable planets are colonized  
**Frequency**: Every 25 turns after formation  
**Target Resolution**: 1920×1080 (scalable)

### Vote Announcement Timing
- Each AI vote announcement: 2-3 seconds display
- Text types out character-by-character (typewriter effect)
- Vote bars animate smoothly when updating
- Brief pause between announcements (1 second)

### Victory Effects
- Triumphant fanfare sound
- Golden glow effect around winner portrait
- Confetti/celebration particles (subtle)
- Vote bar pulses green when threshold reached

### Final War Effects
- Red flash overlay
- Warning klaxon sound
- Enemy portraits gain red border glow
- Dramatic music sting

### Council Convening
- Slow fade-in of chamber
- Delegates appear one by one (quick fade-in per seat)
- Cosmic Wheel hologram pulses with energy
- Ambient background music (ceremonial)

## Edge Cases

### 1. Player is Both Candidate
- Player votes automatically for self
- Skip player voting screen
- Show "You automatically vote for yourself" message

### 2. Two-Race Galaxy
- Both remaining races are candidates
- 67% threshold applies
- If neither has 67%, no decision
- Effectively requires 2/3 population control

### 3. Only Player Remaining
- Council does not convene
- Switch to Survival Victory path check

### 4. Player at War with Both Candidates
- Player must abstain
- Show message: "You cannot vote for your enemies. Your empire abstains."

### 5. All Races Abstain
- "No Quorum" result
- Council reconvenes in 25 turns
- Show special message about galactic indecision

### 6. Exactly 50/50 Split
- Neither reaches 67%
- "No Decision" outcome
- Both candidates tied message

### 7. Candidate Eliminated Mid-Turn
- Replace with next highest population
- Or win by default if only one remains
- Display notification of succession

### 8. Zero Population Race
- Excluded from voting
- Does not appear in council chamber
- Portrait grayed out with "EXTINCT" label

## Accessibility Features

### Screen Reader Support
- All vote weights announced with percentages
- Candidate information read in full
- Vote announcements include race name and decision
- Victory/defeat outcomes clearly announced

### Color Blind Considerations
- Vote bars use patterns in addition to colors
- Winner indicated with star icon, not just color
- Abstain uses distinct hatching pattern
- War declarations use symbol (⚔️) not just red color

### Visual Impairment Support
- High contrast mode available
- Large text option for speeches
- Clear borders around interactive elements
- Animated elements can be disabled
