# Reports & Statistics UI - Detailed Wireframe Specification

## Overview

The Reports screen (F7) in Hamster of Orion provides comprehensive empire analytics, galactic rankings, historical graphs, and strategic intelligence. This is the primary screen for players to assess their standing relative to other empires, track progress over time, and make informed strategic decisions. This specification provides detailed ASCII wireframes matching MOO1 behavior with modern web enhancements.

**Reference**: Master of Orion (1993) Reports/Graphs Screen  
**Hotkey**: F7  
**Target Resolution**: 1920×1080 (scalable)

## Data Display Specifications

### Power Ranking Formula

The overall power ranking is calculated using weighted components:

```
Overall Power = (Population Score × 0.18) +
                (Production Score × 0.20) +
                (Technology Score × 0.15) +
                (Military Score × 0.35) +
                (Colony Score × 0.12)

Where each score is normalized to 0-100 based on:
- Highest value in galaxy = 100
- Proportional scaling for others
```

### Intelligence Accuracy

Intel accuracy for other empires depends on espionage:

| Spy Network Level | Accuracy |
|-------------------|----------|
| None              | ±50%     |
| Basic             | ±30%     |
| Moderate          | ±15%     |
| Extensive         | ±5%      |
| Infiltrated       | Exact    |

Display format: `1,850 (est.)` for estimates, `1,850` for exact.
